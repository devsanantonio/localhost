# localhost:210 brand files

The `:210` is a port number and San Antonio's area code.

| File | Use |
|---|---|
| `localhost-210-wordmark-dark.svg` / `-light.svg` | The mark alone. `dark` is for dark backgrounds, `light` for light ones. |
| `localhost-210-lockup-dark.svg` / `-light.svg` | The mark with "Build with San Antonio's open data · A DEVSA project" |
| `localhost-210-icon.svg` / `.png` | `:210` on a black square, for avatars and small spaces |

Set in Geist Mono SemiBold, converted to outlines. The orange is `#ff8200`, from the DEVSA logo, and it's always the color of `:210`. Keep the DEVSA logo separate from this mark rather than combining them.

Describe the data as the City's, the County's and VIA's, never as DEVSA's: "a DEVSA project", not "data from DEVSA".
